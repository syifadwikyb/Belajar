# 📝 Task Management App (Fullstack)

Aplikasi manajemen tugas (*Task Management*) fullstack yang dibangun menggunakan **Next.js (App Router)** di sisi frontend, **Express.js** di sisi backend, dan **Supabase (PostgreSQL)** sebagai database.

---

## 📁 Struktur Proyek

```text
.
├── backend/                # REST API (Express.js + Supabase Client)
│   ├── src/
│   │   ├── config/        # Konfigurasi Supabase Client
│   │   ├── Tasks/         # Controller, Model/Service, Route untuk Task
│   │   └── index.js       # Entry point Express server
│   ├── .env               # Environment variable backend
│   └── package.json
│
├── frontend/               # UI Web App (Next.js 14 + Tailwind CSS + TypeScript)
│   ├── app/               # Next.js App Router (pages & layout)
│   ├── components/        # Reusable UI components (TaskForm, TaskList, dll)
│   ├── lib/               # Helper API fetcher
│   ├── types/             # TypeScript type definitions
│   ├── .env.local         # Environment variable frontend
│   └── package.json
│
└── README.md
```

## ⚙️ Prasyarat (Prerequisites)

Pastikan sistem Anda telah terinstal:

- NPM (bawaan Node.js) atau Yarn / PNPM / Bun

## 🛠️ Panduan Membuat & Install dari Awal (Inisialisasi Project)

Jika Anda ingin membuat ulang atau memahami cara inisialisasi dari folder kosong:

### 1. Inisialisasi Backend (Express.js)
```bash
# 1. Buat dan masuk ke folder backend
mkdir backend
cd backend

# 2. Inisialisasi package.json
npm init -y

# 3. Install dependencies Express & Supabase
npm install express cors dotenv @supabase/supabase-js
```

Di file `package.json` backend, tambahkan script:
```json
"scripts": {
  "start": "node src/index.js",
  "dev": "node --watch src/index.js"
}
```

---

### 2. Inisialisasi Frontend (Next.js + Tailwind CSS + TypeScript)
Gunakan CLI resmi `create-next-app` untuk membuat Next.js dengan Tailwind CSS terkonfigurasi otomatis:

```bash
# Dari root direktori (sejajar dengan folder backend)
npx create-next-app@latest frontend
```

Saat muncul prompt interaktif, pilih:
- ✔ Would you like to use **TypeScript**? … **Yes**
- ✔ Would you like to use **ESLint**? … **Yes**
- ✔ Would you like to use **Tailwind CSS**? … **Yes**
- ✔ Would you like your code inside a `src/` directory? … **No** (atau Yes sesuai preferensi)
- ✔ Would you like to use **App Router**? (recommended) … **Yes**
- ✔ Would you like to use Turbopack for `next dev`? … **No / Yes**
- ✔ Would you like to customize the import alias (`@/*`)? … **No**

> 💡 *Perintah di atas akan secara otomatis menginstal `next`, `react`, `react-dom`, `tailwindcss`, `postcss`, `autoprefixer`, dan menyiapkan konfigurasi `tailwind.config.js` & `globals.css`.*

## 🗄️ Setup Database (Supabase)

1. Buat project baru di **Supabase Dashboard**.
2. Masuk ke menu **SQL Editor** di dashboard Supabase Anda.
3. Jalankan query SQL berikut untuk membuat tabel `tasks`:

```sql
CREATE TABLE tasks (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    description TEXT,
    status VARCHAR(50) DEFAULT 'pending' CHECK (status IN ('pending', 'in_progress', 'completed')),
    created_at TIMESTAMPTZ DEFAULT NOW(),
    updated_at TIMESTAMPTZ DEFAULT NOW()
);
```

4. Buka menu **Project Settings** > **API** di Supabase untuk mendapatkan:
   - **Project URL** (`SUPABASE_URL`)
   - **anon / public key** (`SUPABASE_ANON_KEY`)

## 🚀 Menjalankan Backend (Express.js)

1. **Masuk ke direktori backend:**
   ```bash
   cd backend
   ```

2. **Install dependensi (jika belum):**
   ```bash
   npm install
   ```

3. **Konfigurasi Environment Variable (`.env`):**
   Buat file `.env` di dalam folder `backend/`:
   ```env
   PORT=5000
   SUPABASE_URL=https://your-project-id.supabase.co
   SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

4. **Jalankan Backend Server:**
   - Mode Development:
     ```bash
     npm run dev
     ```
   - Mode Production:
     ```bash
     npm start
     ```

Backend berjalan di: `http://localhost:5000`

---

## 💻 Menjalankan Frontend (Next.js 14)

1. **Buka terminal baru dan masuk ke direktori frontend:**
   ```bash
   cd frontend
   ```

2. **Install dependensi (jika belum):**
   ```bash
   npm install
   ```

3. **Konfigurasi Environment Variable (`.env.local`):**
   Buat file `.env.local` di dalam folder `frontend/`:
   ```env
   NEXT_PUBLIC_API_URL=http://localhost:5000
   ```

4. **Jalankan Frontend Dev Server:**
   ```bash
   npm run dev
   ```

Aplikasi web dapat diakses di browser melalui: `http://localhost:3000`

## 📡 API Endpoints (Backend)

| Method | Endpoint | Deskripsi |
|---|---|---|
| `GET` | `/health` | Cek status kesehatan server API |
| `GET` | `/health/database` | Cek koneksi ke database Supabase |
| `GET` | `/tasks` | Mengambil seluruh daftar tugas (bisa filter `?search=` dan `?status=`) |
| `GET` | `/tasks/:id` | Mengambil detail 1 tugas berdasarkan ID |
| `POST` | `/tasks` | Menambahkan tugas baru |
| `PUT` | `/tasks/:id` | Mengupdate tugas berdasarkan ID |
| `DELETE` | `/tasks/:id` | Menghapus tugas berdasarkan ID |

### Contoh Request Body `POST /tasks`:
```json
{
  "title": "Belajar Next.js",
  "description": "Mempelajari Server Component dan Client Component",
  "status": "pending"
}
```
